### Step 4: Using Ideogram Canvas for Inpainting and Extensions

Ideogram Canvas is the in-browser editor that lets you fix specific parts of a generated image without regenerating the entire thing.

**Canvas capabilities:**
- **Inpainting:** Select a region (e.g., a misspelled word, an unwanted artifact) and describe what should replace it.
- **Background extension:** Expand the canvas area and have Ideogram fill the new space contextually — useful for adjusting aspect ratios.
- **Re-styling:** Apply a different style preset to an existing image while preserving composition.

**Practical Canvas workflow — fixing a typo:**

1. Generate a poster. The headline says "WELCOME TO THE CONFERNCE" (missing the second 'E').
2. Instead of regenerating (which might change the layout), open Canvas.
3. Select the area around "CONFERNCE" with the brush tool.
4. Prompt: "Replace this word with 'CONFERENCE' — all capital letters, matching the existing font style and color."
5. Ideogram inpaints only the selected region.

This preserves the composition you already like while fixing the specific flaw. It is significantly more efficient than full regeneration, especially for posters where the overall layout matters as much as the text.

### Step 5: Batch Generation via API for Marketing Teams

For teams producing volumes of localized or branded visuals, the Ideogram API (paid plans) enables programmatic generation.

```python
import requests
import time

API_KEY = "your_ideogram_api_key"
HEADERS = {
    "Api-Key": API_KEY,
    "Content-Type": "application/json"
}

def generate_image(prompt, style_type="DESIGN", aspect_ratio="ASPECT_2_3"):
    """Submit a generation and return the image URL."""
    
    payload = {
        "image_request": {
            "prompt": prompt,
            "aspect_ratio": aspect_ratio,
            "model": "V_3",
            "style_type": style_type,
            "magic_prompt_option": "AUTO"
        }
    }
    
    response = requests.post(
        "https://api.ideogram.ai/generate",
        headers=HEADERS,
        json=payload
    )
    
    data = response.json()
    if "data" in data:
        return data["data"][0]["url"]
    else:
        raise Exception(f"Generation failed: {data}")

# Batch: generate localized hero images for 5 markets
markets = [
    {"city": "San Francisco", "date": "October 15"},
    {"city": "Tokyo", "date": "October 22"},
    {"city": "Berlin", "date": "October 29"},
    {"city": "São Paulo", "date": "November 5"},
    {"city": "Sydney", "date": "November 12"},
]

for market in markets:
    prompt = (
        f"A modern tech conference poster. Headline: 'AI BUILDERS SUMMIT 2026' "
        f"in bold white. Subtitle: '{market['city']} · {market['date']}'. "
        f"Background: dark gradient with geometric patterns. Design preset."
    )
    
    try:
        url = generate_image(prompt, style_type="DESIGN", aspect_ratio="ASPECT_2_3")
        print(f"{market['city']}: {url}")
    except Exception as e:
        print(f"{market['city']} failed: {e}")
    
    time.sleep(3)  # Respect rate limits
```

**API best practices:**
- Always include error handling — API rate limits and model availability can cause intermittent failures.
- Store generated images to your own CDN; do not rely on Ideogram URLs as permanent storage.
- For production use, generate 2-3 variations per prompt and have a human select the best one. Fully automated pipelines still benefit from a review step.
