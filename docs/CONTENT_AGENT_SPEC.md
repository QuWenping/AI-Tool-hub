## 2. 内容质量核心原则（E-E-A-T）

### Experience（经验）
- 禁止虚构个人体验（如"我们使用 30 天后发现"）
- 正确：Based on available features and practical workflows...

### Expertise（专业）
文章必须体现：工作场景理解、技术分析能力、使用限制分析、替代方案比较。不能只是功能介绍+官网复制。

### Authoritativeness（权威）
- 作者统一：AI Tool Hub Research Team
- 禁止虚构专家、测试团队、Reviewer 经历

### Trustworthiness（可信）
- 平衡评价、展示优缺点、明确信息来源、标注更新时间
- 禁止绝对化宣传、虚假排名、夸大效果

## 3. 禁止内容规则

1. **禁止虚构测试经历**：We tested / Our team used / 除非输入数据包含真实测试记录
2. **禁止虚构专家身份**：Reviewed by X with Y years experience（除非真实）
3. **禁止过度营销语言**：best ever / ultimate / number one / game changer / revolutionary
4. **禁止绝对排名**：#1 / Winner / clear champion → 改用 Best suited for / Better choice when

## 4. 内容结构标准模板

每篇 AI 工具文章必须包含：
- Title（避免 The Only AI Tool You Need）
- Introduction（150-200 字，回答：是什么/解决什么/谁适合）
- Quick Summary（Best For / Pricing / Main Features / Learning Curve / Alternatives）
- What is [Tool]?（公司背景、产品定位、核心能力）
- Key Features（每个功能含 What it does / Why it matters / Limitations）
- Use Cases（基于真实场景）
- Pros and Cons（≥3 Pros + ≥3 Cons）
- Pricing（不猜测，可能变化时注明 Check official website）
- Comparison Section（不要简单宣布 Winner）
- Alternatives（≥3 个替代方案，每个含 Best for / Main difference）
- Final Recommendation（Choose X if... / Choose Y if...）
- FAQ（≥5 个，来自用户搜索意图）

## 5. SEO 规范

- Title：50-60 字符，含核心关键词
- Meta Description：150-160 字符
- URL：简洁格式，避免长尾关键词堆砌

## 6. AI 生成检测优化

避免：Firstly/Secondly/In conclusion/It is worth noting 等固定 AI 句式。
增加：具体场景、限制条件、使用建议。

## 7. Affiliate 合规

如有商业链接，必须增加 Disclosure。

## 8. 图片规范

每篇 3-5 张，禁止无版权图片、禁止 AI 生成冒充产品截图。

## 9. Fact Checking 流程

发布前验证：产品名称 → 价格 → 功能描述 → 是否存在虚构体验 → 是否存在夸张宣传。

## 10. 发布评分系统
